Live Rebuilt from public data every run

Find the companies that are about to buy.

A job board is a public statement of where a company is about to spend money. This reads 30 public job boards, finds the hiring patterns that mean a company is scaling go-to-market, and hands you a ranked list — with the exact job posting that proves each one. No API keys. No paid data vendor.

Ranked accounts

Live output from the last run. Open any row to see the job postings behind the score — every link goes to the company's own careers page.

The five signals

Every weight is visible and editable in one file. You should be able to disagree with a number and change it, rather than trust a black box.

What it does that a keyword search doesn't

Counts roles, not postings. One job listed in five cities is one job. Counting it as five is the fastest way to look unserious to anyone who knows how a job board works.
Caps each signal. A company with forty open sales seats doesn't out-rank a company standing up its first go-to-market engineering team.
Carries its evidence. Every score opens into the exact job postings behind it, so the number is checkable instead of just asserted.
Reports failures out loud. A board that can't be read is listed as a failure, never quietly counted as a zero.

Run it yourself

Python 3.9+, standard library only. No install step, no credentials, no account. A full run takes about three seconds.

git clone https://github.com/Duckky153/gtm-signal-engine
cd gtm-signal-engine

python3 -m engine.run              # writes signals.json, signals.csv, report.md
python3 -m unittest discover -s tests   # 14 tests

Honest limits

  • It reads job titles, not job descriptions. A posting that names Clay or Apollo in the body is a strong signal this version doesn't catch yet.
  • It sees public job boards only. A company hiring quietly is invisible to it.
  • Hiring intent isn't the same as buying intent. This tells you who to research first. It doesn't close anyone.
  • The 30-company list is a demonstration. Pointing it at a real target market is a change to one file.
