GTM Signal Engine

A job board is a public statement of where a company is about to spend money.

This reads 30 public ATS boards, finds the hiring patterns that mean a company is building or scaling go-to-market, and ranks every account by how ready it is to buy — with the exact requisition behind every score. No API keys. No paid data vendor. Clone it and you get the same numbers.

Ranked accounts

Live output from the last run. Open any row to see the requisitions that produced the score — every link goes to the company's own careers page.

The five signals

Weights are visible and editable in engine/signals.py. You should be able to disagree with a number and change it, rather than trust a black box.

What it does that a keyword search does not

  • Counts roles, not postings. One requisition listed in five cities is one role. Scoring on raw posting count is the fastest way to look unserious to anyone who knows how an ATS works.
  • Caps each signal. A company with forty open AE seats does not out-rank a company standing up its first GTM engineering team.
  • Carries its evidence. Every score expands into the exact requisitions behind it, so the number is auditable rather than asserted.
  • Reports failures out loud. A board that cannot be read is listed as a failure, never silently dropped as a zero.

Run it yourself

Python 3.9+, standard library only. No install step, no credentials.

git clone https://github.com/Duckky153/gtm-signal-engine
cd gtm-signal-engine
python3 -m engine.run              # writes out/signals.{json,csv} and out/report.md
python3 -m unittest discover -s tests

Honest limits

  • Signals come from job titles, not descriptions. A posting that names Clay or Apollo in its body is a strong signal this version does not yet read.
  • It sees public ATS boards only. A company hiring privately is invisible to it.
  • Hiring intent is correlated with buying intent, not identical to it. This ranks who to research first — it does not close anyone.
  • The target list is 30 companies chosen to prove the mechanism. Pointing it at a real ICP is a change to one JSON file.
